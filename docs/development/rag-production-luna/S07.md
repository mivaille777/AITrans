## 行为与边界

- Graph 只有在显式配置启用后才构图/检索；Graph Only、GV、GVB 复用现有融合及重排入口。
- 所有读取使用同一 active generation/allowlist 快照。找不到原文、同名未消歧、来源 hash/span 不符、过期或越权时不输出候选；过滤失败的边不能作为隐藏桥继续扩展。
- 最多 2 跳，默认最多 8 seeds、64 nodes、128 个来源路径计数、256 次边检查、250 ms 协作截止时间。每跳前缀路径绑定该跳原文 span，保留两跳所需的逐边证据；双向邻接导航不改变原始关系方向。
- SQLite 有限等待/进度回调和循环检查截止时间。同步 `VectorStore.get_chunk` 已经阻塞时不能强制中断，返回后丢弃超时结果；不能据此承诺硬墙钟 250 ms 或生产 P95。
- 图失败/超时保持错误诊断并降级已有通道；所有已启用通道均失败时继续抛出原有检索异常。

### 真实模型与真实存储的功能验证

隔离脚本：`python data/benchmarks/s07/smoke_graph.py`，最终退出码 0。

- 输入明确为合成 TXT：`Alpha uses Beta. Beta uses Gamma. Gamma uses Delta.`；1 个实际解析 chunk。真实 `deepseek-v4-flash` 输出，经原有严格 schema/span 校验后得到 3 条关系，实际 Qwen3 embedding + Qdrant/BM25/SQLite 完成入库与召回。
- V/B/VB/G/GV/GVB 各执行 3 个实际检索请求。9 个启用图的请求全部 `graph_hits=1`，候选包含原始 chunk、通道 rank/score 与可解析的逐边 span；显式不存在文档与 active generation 的交集为空，返回 0 候选；删除后 0 图命中，六张图表全部 0 行。
- 共记录 2 次真实模型调用，输入合计 102 字符：首次导入和一次重建。验证脚本曾误用 dataclass 序列化、错误参数及空 filter 的历史语义，三次退出 1 记录均保留；修复脚本后复用先前已严格校验的真实 generation，最终运行新模型调用 0，不使用金标填充输出。token/账单未返回，记录为 null。
- 固定标注链的 NetworkX 3.6.1 PPR：Alpha 0.302224、Beta 0.358176、Gamma 0.238316、Delta 0.101285；两跳能找到 Beta→Gamma 的原文，单跳不能。仅作为算法/证据合同的参考。[NetworkX 官方接口](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.link_analysis.pagerank_alg.pagerank.html)支持 personalization 和边权；生产路径没有引入 NetworkX/PPR。
