## 改动与合同

- 新增 `SourceSpan`，以 `version=1` 和 `coordinate_space=normalized_document_text` 标识定位协议。`start_char/end_char` 是解析器归一化全文中的 Python Unicode 码点偏移，采用左闭右开区间；可附原文 URI 与起止页。
- Span 保存原始文档 hash、归一化全文 hash 和所选片段 hash。`resolve_source_span()` 检查文档版本（调用方提供时）、全文版本、范围和片段 hash；任何失配明确报错，不返回近似位置。
- `DocumentChunk.source_span` 为可选字段。若存在，要求它的偏移与旧 `start_char/end_char`、已有 document hash/source URI 一致；老 JSON 没有此字段仍解析为 `None`。当前任务未给已有 chunk 自动生成 span，集成留到 S02.3。
