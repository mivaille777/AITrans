## 改动与合同

- KnowledgeLibraryService 继续将导入、重导入、删除委托给已版本化的 IndexService。缓存只在一次新的 READY generation 发布后失效；索引失败时保留旧 active generation 的 outline cache，避免失败重导入把旧索引与已变更磁盘文件混在一起。
- `IndexManifest.delete()` 删除文档及其全部 generation 目录；保存失败时恢复内存快照，避免磁盘状态和内存状态分叉。
- 新增集成烟测生成可读文本层 PDF、DOCX、HTML、TXT 文件，使用真实 parser、Qdrant Local 和 BM25，覆盖导入、TXT 内容更新、active-only 检索、manifest/Qdrant/BM25 对账、关闭重开后检索、逐文档删除和再次重启后的清理。
- 知识 API 测试确认重导入切到新 generation 并保留旧版；删除后向量、BM25 和 manifest generation 均清空。嵌入失败时旧 READY generation 和 outline cache 保持；恢复后新版本发布并清除旧 cache。

## Bad Case、安全与结论

- `format-import-restart-delete`：四种实际文件格式均成功解析、索引、检索、重启恢复和删除；重启后 vector/BM25/manifest 均为 0 个残留文档/chunk/generation。
- `failed-reimport-cache-consistency`：embedding 失败后 manifest 仍为旧 READY generation，outline cache 保持旧内容；重试成功后切换新 generation 并失效旧 cache。
- 同一 TXT 重导入后旧 generation 仍保留，但检索只见当前 READY generation；只读审计三库对账为 consistent。已覆盖越权范围以外的生命周期安全门；业务权限及 citation/faithfulness 指标未在此任务重测。
