## 兼容性与坏例

- `S03.1-model-id-change`：更换模型 ID 后，索引服务拒绝复用并建立新 generation。
- `S03.1-dimension-change`：4→3 维时拒绝复用，写入新 fingerprint 和 generation，旧 READY generation 转为 RETIRED；不会把旧向量当作新维度索引。
- `S03.1-prompt-prefix-change`：相同模型/维度下更换 prompt 标识会改变 fingerprint digest。
- manifest 中注入与顶层模型 ID 不同的 fingerprint 会被拒绝；旧 JSON 无 fingerprint 字段仍可读取。
