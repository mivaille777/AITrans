## 版本、来源与恢复合同

SQLite 含 entity、alias、relation、relation_span、chunk_entity、graph_generation，外键级联删除、WAL、每个 generation 单事务。图的 READY 仅表示完整写入；manifest 是唯一发布指针。查询要求显式 scope、文档 allowlist 和 active generation，不自行选择“最新图”。1200 文档范围用例通过，空范围、不同 scope 和旧 generation 返回空。

别名按文档/generation 保存，共享实体不会泄露未授权文档的别名。关系 payload 与 SQL 中的 scope/document/generation/端点身份不一致会报错。所有关系需能在原 chunk 的 hash、URI 和范围内精确回源；节点或模型摘要不能作为 citation。

旧 READY 图与 vector/BM25 一样保留供回滚；正常读取看不到旧边。“0 旧边残留”按 active 读取与删除后物理清理分别验证，未擅自删除供回滚的旧版本。恢复在 manifest 标记中断 generation 失败后清理未发布图；重启用例覆盖此顺序。

Graph 默认不注入现有 API。S07 需要把同一个 scope/GraphIndexer 接入导入、删除和在线检索，不能只接查询而遗漏生命周期。

## 真实模型小集

使用配置中的 `deepseek / deepseek-v4-flash`，`research.memory.extract@graph-1.0.0`；source adapter 版本包含 `unique-whitespace-v1`。沿用原 JSON schema 和调用客户端，Graph 专用提示要求最多 3 条短句证据、先声明端点和合法 claim_index。

10 个固定合成用例，6 条 gold：TP=6、FP=0、FN=0，relation precision/recall 均 1.0。G09 被动语态原先漏边，现方向正确；否定/不确定/共现/表格负例无发布边。这是小型功能集，不能代表真实论文抽取质量，也不是已批准生产门槛；未计算实体/消歧生产 precision/recall。

模型修改 PDF 换行导致引文不完全相同时，只允许唯一的空白等价匹配，恢复为原文实际子串后仍执行严格校验。改词、标点不同和多个可匹配位置均不接受。结构/证据校验错误最多重试一次，成功重试计入诊断；网络、配置和持续错误不会伪装成空成功。
