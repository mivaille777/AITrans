## 生命周期改动

`backend/rag/sparse/store.py` 的持久 JSON 新增 `tokenizer_version`。无版本的旧索引及版本不同的索引在启动时，从保存的真实 DocumentChunk 重新分词，并原子保存当前版本；查询和索引用同一 tokenizer。保存源 chunk、SourceSpan、generation 的合同保持兼容。

`tests/rag/test_sparse_lifecycle.py` 验证无版本旧 JSON/旧版本迁移、重建移除旧 chunk、定向删除后的重启、inactive generation、非 allowlist 文档和显式空 active scope。注入测试中 **过期/越权候选均为 0**。这验证存储层的显式 scope；全应用范围未知时停止检索的接线仍由后续共享 scope 编排完成。
