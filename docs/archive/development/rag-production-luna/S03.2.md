## 改动

- `VectorStore.search` / `QdrantLocalVectorStore.search` 增加可选 `allowed_document_ids`。`None` 保持旧 API 行为；空列表、与请求 `document_ids` 无交集的 allowlist，以及空 active generation 集均直接返回空结果。
- `backend/rag/stores/base.py` 集中计算请求文档与授权 allowlist 的交集；Qdrant 将该集合和每文档 active generation 同时放入服务端过滤器。
- Qdrant 返回后先核验原始 payload 文档 ID 与 generation，再反序列化 chunk；随后复核 chunk 内的文档/generation，拒绝错误文档、过期 generation、generation 缺失或 payload 两处 generation 不一致。
- generation 删除后，即使旧 generation 仍存在，也不能通过 active generation 查询返回。旧调用不传 allowlist 时保持兼容。

## 坏例与安全结果

- `S03.2-empty-allowlist`：授权集为空时，在创建/查询 collection 前返回 0 候选。
- `S03.2-disjoint-document-filters`：请求文档集与授权集无交集时返回 0 候选。
- `S03.2-qdrant-scope-leak`：注入未授权文档结果，post-filter 将其丢弃。
- `S03.2-stale-generation`：注入旧 generation、缺失顶层 generation、顶层与 metadata 矛盾的结果；只保留匹配 active generation 的授权 chunk。
- `S03.2-post-delete`：删除当前 generation 后，搜索 0 结果；残留旧 generation 不会被 active pointer 查询读取。
- 本任务的越权候选和失效 generation 候选均为 0；没有执行生成或 citation 校验，未测半成品发布、崩溃计数和人工 Debug Studio Trace。
