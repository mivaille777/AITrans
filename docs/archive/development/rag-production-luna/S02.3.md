## 改动

- 结构分块和语义分块都为每个文本 chunk 生成 `SourceSpan`，保存规范化全文的 Unicode 码点范围、文档 hash、原文 URI、页范围、全文 hash 和 quote hash。表格、公式、图注等由文本解析器产出的 chunk 保留相同来源锚点。
- `IndexService` 在向量化和开始写入 generation 前检查：chunk 非空、文档 ID/hash/URI 一致、chunk 文本等于规范化全文切片、span hash 可校验、页范围与 `NormalizedDocument.pages` 相交结果完全一致。支持不认识 span 的兼容 chunker 时，只有 offset 与文本精确吻合才补建 span；任何错位都失败关闭。
- 结构/语义 chunker 版本分别升为 `hierarchical-special-block-v4` / `hierarchical-semantic-v5`，强制旧 generation 按正常生命周期重建，避免复用没有 SourceSpan 的旧 chunk。
- 故障注入将 chunk 文本改成原文不存在的内容或把实际页范围 `[1,2]` 篡改为 `[2,2]`，两者均在 embedding/发布前被拒绝；已有 READY generation 和旧 chunk 保留。
- 新增 Qdrant payload 与 BM25 JSON 重启用例，验证嵌套 SourceSpan 能随候选恢复。
